# DataScience_Kelompok-apa
## Proyek Data Science 2026/2027

Proyek kami berjudul "Analisis dan Prediksi Customer Satisfaction Terhadap Karakteristik Pengiriman dan Ulasan pada E-commerce" menggunakan data transaksi Olist Brazilian Ecommerce dari kaggle.  

Olist adalah platform marketplace asal Brasil yang menghubungkan usaha kecil dengan pelanggan melalui berbagai kanal penjualan. Dataset publik Olist di Kaggle memuat sekitar 100 ribu pesanan pada periode 2016-2018 dan tersebar pada beberapa tabel relasional, diantaranya pesanan, item pesanan, pelanggan, penjual, produk, pembayaran, ulasan, dan geolokasi. Karakteristik ini menjadikannya sumber data yang kaya untuk latihan data science, karena menuntut penggabungan tabel, penanganan data tidak seimbang, rekayasa fitur dari data waktu dan lokasi, serta perhatian terhadap kebocoran data. Pada pesanan yang sudah terkirim tersedia tanggal estimasi dan tanggal aktual kedatangan, sehingga status keterlambatan dapat dirumuskan secara jelas sebagai variabel target.

Untuk modeling kami ingin mengembangkan model supervised learning menggunakan pendekatan `binary classification` untuk memprediksi status keterlambatan pengiriman pesanan ke dalam dua kelas, yaitu tepat waktu dan terlambat.
